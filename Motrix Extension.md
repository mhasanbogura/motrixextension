# Motrix Extension

This package contains the cross-browser Motrix Extension and its native Media Picker helper.

## Contents

- `Motrix Extension/Chrome/` — Chrome/Chromium MV3 extension build.
- `Motrix Extension/Firefox/` — Firefox MV2 extension build.
- `Media Picker/` — Windows and Linux/macOS native resolver installer, including the optional local `cookies.txt` workflow.

## Installation

Install the extension from the browser’s extension management page by loading the matching Chrome or Firefox folder from `Motrix Extension/`. Then run the appropriate installer from `Media Picker/` once and restart the browser.

Keep any real social-media cookies file private. The included `cookies.txt` is only an empty template; do not share or commit a file containing real cookies.
